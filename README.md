# GAIA სასკოლო AI კლუბები — საიტი

საპილოტე სემესტრის (გაზაფხული 2027) საიტი: პროგრამის აღწერა, აკადემიური კალენდარი, ღონისძიებები, ნიუსლეთერები და ცალკე გვერდი მენტორების პროგრამისთვის.

- `index.html` — მთელი საიტი ერთ ფაილში (CSS, JS, ლოგო და მონაცემების ასლი შიგნითაა).
- `data/*.json` — ღონისძიებების, ნიუსლეთერების, გვერდების ტექსტებისა და თასქების საწყისი მონაცემები.

ადმინ პანელი და ცოცხალი მონაცემები მუშაობს claude.ai-ზე გამოქვეყნებულ ვერსიაში. სხვა ჰოსტინგზე (მაგ. GitHub Pages) საიტი აჩვენებს `index.html`-ში ჩაშენებულ ასლს, ადმინ პანელის გარეშე.
